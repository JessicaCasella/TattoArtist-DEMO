# Ink Studio

Demo de una web para un estudio ficticio de tatuajes en Montevideo.

- Fondo por capas con movimiento del mouse y profundidad al hacer scroll.
- Portada centrada e iconos de redes dibujados en SVG.
- Galería de tres flashes con ampliación en un diálogo.
- Diseño responsive y respeto por la preferencia de movimiento reducido.

## Ejecutar

No requiere dependencias ni compilación. Desde la carpeta del proyecto:

```sh
python -m http.server 5173 --bind 127.0.0.1
```

Abrir http://127.0.0.1:5173 en el navegador.

## Archivos

`index.html`, `style.css` y `script.js` contienen la web. `assets/` contiene las ilustraciones generadas para esta demo.

Los enlaces sociales llevan a las páginas de las plataformas. El estudio y su agenda son ficticios.
